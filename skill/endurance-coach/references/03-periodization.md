# 03 · 周期化与赛季规划（W2/W5 必读）

> 原则：**先切阶段，再排周，再排日**。不允许跳过阶段直接给「明天跑什么」。

## 1. 阶段判定（按距 A 赛周数）

| 距 A 赛 | 阶段 | 目标 |
|---|---|---|
| >12 周 | 基础期 → 强化期 | 有氧容量、阈值打底 |
| 8–12 周 | 强化期 | 阈值 + 专项耐力 |
| 4–8 周 | 巅峰期 + 专项 | 比赛配速专项、长距离峰值 |
| <4 周 | 减量期 | 保状态、去疲劳 |

没有 A 赛时：按 4 周小周期循环（3 周渐进 + 1 周减量），周量在可恢复范围内缓慢上台阶。

## 2. 全马框架（示例：14 周，example）

按 ai-running-coach 的阶段切分表（7–12 周：基础 35% / 强化 30% / 巅峰 20% / 减量 15%），
并把减量定为固定 2 周（总周数 >10 时 2–3 周）：

| 阶段 | 周次 | 周量（占峰值%） | 要点 |
|---|---|---|---|
| 基础期 | W1–W3 | 50% → 60% | 建立周节奏，每周 1 次质量课，长距离 15–18km |
| 基础期 | W4 | 55% | 减量周（−12%），只保留 1 次质量课 |
| 强化期 | W5–W7 | 65% → 78% | 阈值课加量，长距离 20–24km，强度占比 ≤25% |
| 强化期 | W8 | 70% | 减量周，质量课降组数 |
| 巅峰期 | W9–W10 | 88% → 100% | 比赛配速专项，长距离 26–30km，峰值周 |
| 巅峰期 | W11 | 88% | 赛前倒数第二个完整周，保留 1 次完整比赛配速课 |
| 减量期 | W12 | 75% | 量降 20–25%，强度保留（短间歇） |
| 减量期 | W13 | 55% | 长距离缩到 16–18km，质量课 2×10min |
| 减量期 | W14 | 40% + 比赛 | 赛周：赛前 3 天只做激活，比赛日 42.2km |

> 上表是**框架不是死表**：只要满足「周增幅 ≤10%、每 3–4 周有减量周、强度占比 ≤25%、质量课间隔 ≥1 天」，可按状态 ±20% 微调，并写进 `coach/decisions.log.md`。
> 半马 / 10km 的框架按同构缩短：总周数 8–12，长距离峰值分别约 16–18km / 12–14km。

## 2.1 滚动两周维护

赛季表只做「阶段骨架」，实际排课按滚动两周维护：

- **只提交/修改最近两周**的课程，不一次性写满整个赛季。
- **每两周重排后两周**：依据最新恢复状态、阈值测试结果、骑行量。
- 本周剩余 + 下周的完整课表，最迟周三前定稿并提交 COROS；已过去的课程改不了，不回头补。
- 已发生的偏差（出差、伤病、睡不好）在两周窗口内吸收，不整份重写。

> 原因：提前几个月定死的计划，到中段必然与真实状态脱节；两周窗口兼顾「有框架」和「能纠偏」。

## 3. 周结构模板（跑步 4 练）

```
周二 质量课 A：阈值 / 比赛配速（T / M）
周四 质量课 B：间歇或坡（I / R）—— 与周二至少隔 1 天
周六 轻松跑 E 40–60min（心率封顶，不看配速）
周日 长距离 LR（距离优先，心率漂移 <10bpm）
```

拼不出 4 练时：**保周二质量 + 周日长距离**，优先砍周六轻松跑。

## 4. 进阶与减量规则

- 周量增幅 ≤10%；连续 3 周递增后**必须**插一个减量周（−10~15%）。
- 长距离单次增幅 ≤10%，全马备赛峰值 28–30km 封顶。
- 减量期（最后 2 周）：总里程降至峰值的 60–70%，**强度闪一次**（短间歇）保持神经兴奋，赛前 3 天只做激活。
- 比赛周不做任何新刺激（不试新鞋、不试新补给、不加新动作）。

## 5. B 级赛事插队规则

B 赛（如 10km 越野、半马当作训练）**不完整 taper**：

- 赛前 2 天：只做 20–30min 激活 + 拉伸
- 比赛日：按 effort 跑（阈值 90–100% 努力度），不追成绩
- 赛后 1 天：20–30min 恢复跑
- 该周总量从含比赛周的标准里扣，不额外加量

## 6. 生成 → 评审 → 候选（取自 tri-coach）

出周计划时不要直接给结论，走三步并留痕：

1. **生成**：按阶段排 2–3 个候选周（不同强度配比）。
2. **评审**：过第 7 节的七项校验，记下每个候选过/不过的原因。
3. **候选**：输出选中的那一版 + 一句「为什么选它」。

> 不要因为「看起来更努力」就选量最大的那版；选**能执行完**的那版。

## 7. 周计划七项校验（输出前必过）

1. 距离数学：细分距离之和 = 总距离。
2. 周增幅 ≤10%（>10% 截断并标 ⚠️）。
3. 强度占比：T/I/R ≤ 周跑量 25%。
4. 连续强度：不允许连续 2 天高强度后第 3 天还上强度。
5. 质量课间隔 ≥1 天。
6. 长距离前一晚不排质量课；长距离后一天不排质量课。
7. 力量日：动作在库内、不与跑步关键课同日高强度叠加。

## 8. 铁三周期（有明确需求才展开）

| 项 | 规则 |
|---|---|
| 周期长度 | 16–20 周（含 2–3 周减量） |
| 阶段 | 基础 → 强化 → 巅峰 → 减量（与跑步同构，但按三项总量算） |
| 周频次 | 游 2 / 骑 3 / 跑 4（可重叠日：游+跑、骑+游） |
| 砖训练 | 每 2–3 周 1 次（骑→跑），峰值期每周 1 次 |
| 分配目标 | 按**时间**算三项占比（sprint/olympic 约 20/50/30；70.3 约 20/50/30；Ironman 约 15/55/30），每月校验一次 |
| 换项 | 巅峰期起每周 1 次 T1/T2 演练（≤10min 级） |

> 三项分配按时间百分比，不按次数。

## 9. 赛季外的「维持模式」

- 无目标赛事时：每周 3–4 练，保留 1 次质量课 + 1 次长距离，其余 E 跑。
- 休赛期允许每周总量比峰值低 30–40%，但**强度闪一次**（短间歇或坡）避免能力流失。
- 重新开赛季前先做一次基线评估（VDOT / 阈值配速 / 静息心率与 HRV 基线）。
