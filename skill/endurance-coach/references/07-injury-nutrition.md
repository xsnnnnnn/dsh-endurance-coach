# 07 · 伤病分级与补给

> 两条铁律：**不做医疗诊断**；**疼痛 ≠ 可以练过去**。

## 1. 伤病三级（先分级，再决定练不练）

| 级别 | 判定线索 | 处理 |
|---|---|---|
| L0 轻微 | 疼痛 0–3/10，只在特定动作出现，热身后减轻，不影响跑姿 | 可练：减量 20–30%，改软地/少下坡，练后冰敷 10min |
| L1 中度 | 疼痛 4–6/10，跑中加重、跑后持续 >1h，跑姿变形 | 停跑 3–7 天：改骑车/游泳（无痛项目），做康复动作，逐日复评 |
| L2 重度 | 疼痛 ≥7/10、夜间痛、肿胀、关节不稳、跛行、持续 >1 周 | **停练 + 就医**；不做任何替代训练，不自行按摩/拉伸加重 |

**任何级别出现以下情况 → 直接按 L2：** 胸闷、心悸、头晕、发热、静息心率异常升高、单侧小腿肿胀发热（血栓风险）。

## 2. 常见问题速查

| 问题 | 识别线索 | 立即调整 | 康复/预防 |
|---|---|---|---|
| ITBS（髂胫束） | 膝外侧痛，跑下坡/长距离加重 | 停下坡、减量、少跑弯道 | 臀中肌、髋外展训练 |
| 跑者膝 PFPS | 髌骨周围痛，上下楼梯/久坐后痛 | 减量、避免深屈膝 | 股四头肌 + 臀肌，控制步幅 |
| 胫骨应力综合征 | 小腿前内侧弥漫痛，按压痛 | 停跑/改骑游、换软地 | 提踵训练、增加步频、换鞋 |
| 跟腱病 | 跟腱痛、晨起第一步最痛 | 减量、避免上坡冲刺 | 离心提踵（慢速） |
| 足底筋膜炎 | 足跟/足底痛，晨起第一步痛 | 减量、换有支撑的鞋 | 足底筋膜放松、提踵、控制体重 |
| 髌腱炎 | 髌骨下方痛，跳跃/加速痛 | 减强度课 | 离心深蹲 |

> 以上只是**训练调整参考**，不是诊断。持续或复发一律建议就医/找康复师。

## 3. 受伤期的替代训练

| 能做什么 | 条件 |
|---|---|
| 骑行 Z1–Z2 | 疼痛不影响蹬踏、无痛 |
| 游泳（自由泳） | 下肢无痛，避开蹬壁发力 |
| 上肢力量 + 核心 | 不牵涉伤处 |
| 不行就完全休息 | 任何替代训练都加重症状时 |

**停练期间不做「补课」**：恢复后按 85%/70% 起量（中断 3–7 天 / 8–14 天），15 天以上按 mini 重新初始化。

## 4. 补给计算

```bash
python <this skill>/scripts/nutrition.py --duration-min 210 --intensity race
python <this skill>/scripts/nutrition.py --duration-min 120 --intensity moderate --temp-c 30
python <this skill>/scripts/nutrition.py --sweat --weight-before 70.5 --weight-after 69.6 --fluid-ml 800 --duration-min 120
```

（以上命令参数为 example 示例值，实际按自己的体重、时长与环境替换。）

**规则**

| 项 | 公式/区间 |
|---|---|
| 碳水 | 时长<2.5h：30–60 g/h；≥2.5h：60–90 g/h；强度越高取上限 |
| 胶 | 每 22–25g 碳水 = 1 支；每 30–40min 1 支；赛前 15min 1 支 |
| 水 | 400–800 ml/h；湿热取上限 |
| 钠 | 300–600 mg/h；>30℃ 取上限 |
| 出汗率 | `(跑前体重 − 跑后体重 + 补水量) / 时长`（kg→L） |

**测试要求**：任何补给方案必须在长距离课里完整试过 1 次，记录胃肠反应。

## 5. 特殊提醒

- 35 岁以上或有心血管家族史：高强度训练前建议先做运动负荷试验；有基础疾病者遵医嘱。
- 减脂期：不叠加「大跑量 + 大热量缺口」，周跑量增幅与热量缺口二选一。
- 生病：退烧后 48h 内不跑；恢复期前 2 周全 E 跑。
- 高温高湿环境：补水与钠取上限，出现头晕/恶心/停止出汗 → 立即停止并降温就医（热射病风险）。
