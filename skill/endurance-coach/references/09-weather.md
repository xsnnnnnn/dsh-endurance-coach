# 09 · 天气取数与训练修正

> 目标：天气不再是「拍脑袋加一句注意保暖」，而是**可复现的取数 + 确定性阈值 + 写回训练事件**。
> 数据源 Open-Meteo（无需注册或登录）；阈值实现在 `<this skill>/scripts/weather.py`，改阈值就改那个文件，**不要在对话里临时改口**。
> 坐标来自 `coach/athlete.json` 的 `location`，不允许在脚本里硬编码任何人的位置。

## 1. 数据从哪来

| 项目 | 内容 |
|---|---|
| 预报/实况 | `https://api.open-meteo.com/v1/forecast`（模式融合，16 天；取 16 天做缓存） |
| 空气质量 | `https://air-quality-api.open-meteo.com/v1/air-quality`（PM2.5 / US AQI，5 天） |
| 位置 | `coach/athlete.json` → `location`（name / lat / lon / timezone） |
| 比赛地 | `coach/athlete.json` → `weather_policy.venues`（按日期登记的比赛地坐标，可标 `approx: true`） |
| 取数脚本 | `<this skill>/scripts/weather.py`（纯标准库，无第三方依赖） |
| 缓存 | 默认 `coach/.cache/weather.json`，TTL 30 分钟；可用 `--cache` 改路径；断网可回退 ≤36h 旧缓存并标注「可能过期」 |
| 落盘文件（可选） | `--out-md coach/weather-latest.md`（人读）+ `--out-json coach/weather-latest.json`（机读） |
| 刷新方式 | 工作区若自己有定时任务刷新 `coach/weather-latest.md`，晨报优先读该文件；没有就现跑脚本 |

## 2. 怎么用

```bash
# 今天 + 未来 7 天（晨报用）
python <this skill>/scripts/weather.py

# 未来 10 天（周计划用）
python <this skill>/scripts/weather.py --days 10

# 只看某一天（赛前查比赛日；若该日期登记在 venues 会自动切比赛地坐标）
python <this skill>/scripts/weather.py --date 2027-04-18

# 机器可读（含 verdict / pace_adjust / window）
python <this skill>/scripts/weather.py --json

# 临时换地点（比赛在外地，且没在 athlete.json 登记时）
python <this skill>/scripts/weather.py --lat 30.05 --lon 120.10 --name 示例比赛地 --date 2027-04-18

# 落盘（给外部刷新/模型直接读）
python <this skill>/scripts/weather.py --days 10 --out-md coach/weather-latest.md --out-json coach/weather-latest.json

# 指定档案路径 / 缓存路径 / 只用缓存
python <this skill>/scripts/weather.py --athlete coach/athlete.json --cache coach/.cache/weather.json
python <this skill>/scripts/weather.py --offline
```

- 若工作区已有 `coach/weather-latest.md`，**优先直接读文件**，不必为了天气反复执行命令。
- 只有文件缺失 / 日期不是今天 / 用户明确问「最新天气」时才执行脚本。
- `ENDURANCE_COACH_DIR` 可覆盖默认的 `coach` 目录；`--athlete` 优先级最高。
- 退出码：`0` 成功；`2` **天气数据未取到**（必须照实写，禁止编温度）；`3` 参数/日期/档案配置错误。

## 3. 脚本输出怎么读

一天一条，关键字段：

| 字段 | 含义 |
|---|---|
| `tmin/tmax` | 气温区间（℃） |
| `app_min/app_max` | **体感**区间（℃）——所有修正都用体感，不用气温 |
| `wind_max / gust_max` | 10m 平均风 / 阵风（km/h），同时给蒲福风级 |
| `precip_mm / precip_prob` | 日降水量 / 最大降水概率 |
| `pm25_mean / pm25_max / us_aqi_max` | 空气质量（缺省为 None，**不要用 0 代替**） |
| `aqi_label` | 国标 PM2.5 24h 平均分档：优/良/轻度/中度/重度/严重 |
| `verdict` | `适合户外` / `注意` / `不宜户外` / `危险·禁止户外` |
| `flags` | 命中项：雪、结冰、雨雪、雷暴、暴雪、高温、严寒、污染、大风、低温、空气一般… |
| `pace_adjust` | `{low, high, note}`，目标配速建议慢多少 s/km + 原因（脚本算好，别自己加） |
| `window` | 日照内 2 小时「天气最优」窗口（体感/降水概率/风），仅作改时间建议 |
| `confidence` | 预报可信度：高（≤2 天）/中（≤5）/低（≤10）/很低（>10） |

## 4. 阈值与动作

### 4.1 温度（按体感）

| 体感 | 判级 | 动作 |
|---|---|---|
| ≥35℃ | 危险·禁止户外 | 取消户外强度课；清晨或室内低强度 |
| 30–35℃ | 注意/降低 | 配速 +20~35 s/km、质量课减 1 组、补水优先、缩短时长 |
| 26–30℃ | 注意 | 配速 +10~20 s/km，改按心率/体感跑 |
| 20–26℃ | 适合 | 正常执行 |
| 5–20℃ | 适合 | 正常执行（9–14℃ 最适合长距离/质量课） |
| -3–5℃ | 适合/注意 | 热身加倍、戴手套；质量课正常 |
| -8–-3℃ | 注意 | 热身加倍，质量课配速不硬顶（+5~10 s/km 或按心率） |
| -15–-8℃ | 注意/降低 | 质量课转室内，室外只做有氧 |
| ≤-15℃ | 危险 | 停止户外训练 |

### 4.2 风（阵风更关键）

| 阵风 | 跑步 | 骑行 |
|---|---|---|
| <39 km/h（<6 级） | 正常 | 正常 |
| 39–62 km/h（6–7 级） | 避风路线、迎风段放松、间歇避开开阔地 | 改骑行台；户外只做有氧 |
| 62–75 km/h（8–9 级） | 减量或改室内 | 不骑户外 |
| ≥75 km/h（≥10 级） | 改室内 | 不骑户外 |

> 骑行对风更敏感：**CP20/FTP 测试、间歇、下坡** 遇到 ≥6 级阵风一律改骑行台，否则数据也不可比。

### 4.3 降水 / 雪 / 结冰

| 条件 | 判级 | 动作 |
|---|---|---|
| 降水 <0.5mm 且概率 <50% | 适合 | 正常，注意路面 |
| 0.5–5mm 或概率 ≥50% | 注意 | 防水外套、缩短步幅、配速保守 |
| ≥5mm 或概率 ≥80% | 不宜户外 | 跑步机/骑行台，或顺延 |
| 任意降雪（雨夹雪按雪处理） | 不宜户外 | 户外质量课取消；跑步机替代 |
| 最低温 ≤0℃ 且有降水 | 不宜户外（结冰） | 路面/台阶/桥面结冰，不户外 |
| ≥25mm 或 雷暴 | 危险·禁止户外 | 改室内或取消 |
| 大雪 ≥20mm 或 风雪（雪+阵风≥62） | 危险·禁止户外 | 改室内或取消 |

### 4.4 空气质量（国标 PM2.5 日均）

| PM2.5 | 判级 | 动作 |
|---|---|---|
| ≤35 优 / ≤75 良 | 适合 | 正常 |
| 75–115 轻度 | 注意 | 只做有氧，不上质量课；避开早晚高峰 |
| 115–150 中度 | 注意 | 质量课改室内；户外只做短有氧 |
| 150–250 重度 | 不宜户外 | 停止户外训练 |
| >250 严重 | 危险 | 停止户外；改室内或休息 |

> 空气是**加分项**：AQI 预报只到 5 天，超出为 None，不要编一个数字。

### 4.5 其他

- **雾 / 沙尘**：能见度差 → 改室内或白天能见度好的时段；沙尘按 PM2.5 处理。
- **紫外线 ≥7**：防晒、帽子、避开正午。
- **雷暴**：一律不户外（无论距离长短），改室内或取消。

## 5. 天气最优时段（window）

脚本在**日出后 1 小时 ~ 日落**之间，按每 2 小时一段打分选最低：

```
score = |体感-10| × (0.55 偏冷 / 0.9 偏热)
      + 降水概率/10 + 降水量×2
      + 0.4×max(0, 平均风-15) + 0.02×max(0, 阵风-25)
```

- 用途：给「今天/明天几点跑最舒服」的建议，**不是命令**；用户作息固定时只说温度/降水，不硬劝改时间。
- 今天的机会窗口已过（当前时间晚于窗口结束）时脚本会标注「今天已过，明天再看」。

## 6. 和红黄绿灯的关系

- 红灯/黄灯/绿灯只由**身体与负荷**决定（见 `references/02-load-readiness.md`）。
- 天气是**叠加层**：绿灯也可能因为暴雪改室内；红灯也可能因为天气好而只是慢跑。
- 极端天气取消/改室内属于**安全动作**，不占「每周最多 2 次主动调整」额度，但必须记录。

## 7. 写回 Intervals.icu 事件（描述模板）

改某天课程时，把天气与替代方案写进事件的 `workout_doc.description`（用 `add_or_update_event` 写回；**写前先说明并等用户确认**），例如（示例，example）：

```
预计 12-05 周六 0~4℃、大雪 14.5mm（概率 100%）、路面可能结冰：
本课改跑步机完成 8km（Z2）；若必须户外，热身延长到 10 分钟、穿防风外套、缩短步幅，
不做加速跑。室外有积雪/结冰则直接改室内。
```

骑行测试类：

```
预计 12-06 周日 -3~6℃、中雪、路面湿滑结冰：CP20 必须骑行台完成；
无骑行台则顺延到 12-07 下午（-3~7℃、晴、风小），不要在湿滑路面做全力 20 分钟。
```

比赛日（T-3 再确认）：

```
12-13 赛日初步预报：多云 -2~9℃、体感最低 -4℃、无降水、微风。
低温起跑：赛前室内/起点慢跑 2km + 动态拉伸，起跑后 10 分钟再脱外套；
越野路段背阴处可能有霜/薄冰，下坡放慢；补给按 400-800ml/h 取中低值。
```

## 8. 赛前天气流程

| 时间 | 动作 |
|---|---|
| T-10 ~ T-7 | `--date <比赛日>` 看趋势，只做「大概冷/热/雨」的装备预案，**不改计划** |
| T-3 | 再查一次（可信度「中」），确认比赛日相态/风/温度，定装备与热身方案，写进事件描述 |
| T-1 | 查实况 + 次日预报（可信度「高」），定比赛日时段与穿衣层数；发一条提醒 |
| 赛日早上 | 查实况，若雷暴/暴雨/结冰 → 按赛事方决定，不擅自冒险 |

> 越野/山地赛事：比赛地通常比城区低或高 2–4℃，背阴段可能有霜/薄冰；务必用比赛地坐标取预报（`weather_policy.venues` 或 `--lat/--lon`），**不要直接用日常训练地数据**。

## 9. 局限与红线

1. **模式分歧**：0–5℃ 附近「雨 or 雪」不同模式可能不一致。这不改变训练决策（都按湿冷+结冰处理），但**不要对用户断言「一定下雪」**，说「雨夹雪/雪，模式有分歧」。
2. **可信度递减**：第 6 天以后只做趋势参考；第 10 天后不要拿来改计划。
3. **AQI 只到 5 天**：更远写「无数据」，不要估算。
4. **坐标近似**：`approx: true` 的坐标（如山区镇的近似点）小气候以现场为准，别拿它当精确预报。
5. **取不到就认**：网络/文件全失败 → 写「天气数据未取到」，只给原则性建议（如「按体感降速」），**绝不编造温度/湿度/风力**。

## 10. 维护

- 改阈值 → 改 `<this skill>/scripts/weather.py` 的 `classify_day / pace_adjust / heat_tier / cold_tier`，同步改本文档。
- 换地点 → 改 `coach/athlete.json` 的 `location`（不用改代码）。
- 换缓存位置/档案位置 → `--cache` / `--athlete`，或环境变量 `ENDURANCE_COACH_DIR`。
- 调试 → `weather.py --offline`（读缓存）、`--json`（查字段）、`--out-md <tmp>`（试落盘）。
- 不要随意改请求里的 `timezone`：日界会错。用 `location.timezone`（缺省 `auto`，即按坐标当地时区）。
