# 06 · 赛事执行（赛前 2–4 周 / 比赛日 / 赛后）

> 本文件管「最后 4 周怎么练、比赛日怎么跑」。目标时间与目标配速从 `coach/athlete.json` → `races[priority=A]` 读。
> 文中数值是 example（虚构示例，以全马 3:45 为例），实际用你自己的目标换算。

## 1. 赛前 4 周倒排（相对周）

| 距比赛 | 周量 | 关键内容 |
|---|---|---|
| 4 周 | 峰值 90% | 最后一次长距离 26km；比赛配速课 2×20min |
| 3 周 | 峰值 100% | 长距离 28–30km；最后一次完整比赛配速课 |
| 2 周 | 峰值 70% | 长距离 16–18km；T 课缩短到 2×10min |
| 1 周 | 峰值 40–50% | 5km 激活 + 2×1km 比赛配速，其余 E 跑；赛前 2 天只走/拉伸 |

**减量原则**：量降、强度留。赛前 10 天不做新的刺激（不试新鞋/新胶/新路线）。

## 2. 比赛配速策略（示例：全马 3:45，example）

| 段 | 配速 | 心率 | 说明 |
|---|---|---|---|
| 0–5km | 比目标慢 5–10s/km | Z2 上沿–Z3 下沿 | 压住，别跟人流冲 |
| 5–半程 | 目标配速 | Z3 | 示例 5:20/km，前半程约 1:52 |
| 半程–32km | 目标配速 | Z3 上沿 | 稳定，不掉速 |
| 32km–终点 | 目标配速±5s | Z3 上沿 | 有能力才微提速，**不硬冲** |

一票否决：前半程若心率持续超 Z3 上沿，主动降速，不要「找回来」。

## 3. 补给（用 `<this skill>/scripts/nutrition.py` 算，模型只复述）

```bash
python <this skill>/scripts/nutrition.py --duration-min 210 --intensity race
```

默认规则：

| 项 | 量 |
|---|---|
| 碳水 | <2.5h：30–60 g/h；>2.5h：60–90 g/h |
| 能量胶 | 每 30–40min 1 支（约 22–25g 碳水），赛前 15min 1 支 |
| 水 | 400–800 ml/h（按出汗率，湿热取上限） |
| 电解质 | 钠 300–600 mg/h；>30℃ 取上限 |
| 咖啡因 | 赛前 1 支含咖啡因胶（如平时不用，别在比赛日试） |

**必须**：所有补给在训练中先试过至少 1 次；比赛日不尝新。

## 4. 天气修正（赛日）

> 取数、阈值与完整流程见 `references/09-weather.md`；比赛日优先用比赛地坐标（`weather_policy.venues` 里登记后，`weather.py --date <赛日>` 会自动切换）。

- 体感 ≥26℃：配速放慢 10–20s/km；≥30℃：放慢 20–35s/km，补给提前；≥35℃：只保完赛，不保目标时间。
- 体感 ≤-3℃：热身延长一倍，起跑后 10 分钟再脱外套；≤-8℃：按完赛目标降级，注意手指/耳朵。
- 雨雪/结冰：越野下坡放慢，路跑避开桥面/台阶；雷暴、暴雨、暴雪 → 按赛事方通知，不擅自冒险。
- 大风：去程顶风按体感不按配速，回程顺风别冲太快；骑行赛 ≥6 级阵风不骑。
- 无气象数据 → 不臆造温度，只给「按体感降速」的原则。

## 5. 比赛日流程

```
T-3h   正餐：碳水 2–3g/kg（米饭/面/面包），少纤维少油
T-2h   补水 400–500ml，排空
T-1h   1 支胶 + 100–200ml 水；开始动态热身
T-15min 3–5min 慢跑 + 2×30s 加速跑；最后一次上厕所
起跑   前 5km 按「比目标慢 5–10s/km」，不追人
```

**装备检查**（T-1 天晚上）：鞋（已磨合 ≥50km）、号码布、芯片、手表满电、盐丸/胶数量、天气预报。

## 6. 赛后恢复

| 时间 | 动作 |
|---|---|
| 0–30min | 补碳水 + 蛋白（1.0–1.2g/kg 碳水 + 20–30g 蛋白），补水 |
| 当天 | 不泡热水澡、不按摩小腿、抬高腿 |
| 1–3 天 | 只走路/极轻松骑车，不做跑 |
| 4–7 天 | 20–30min E 跑 2 次，主动恢复 |
| 2 周后 | 恢复常规训练量；做一次复盘 |

## 7. 铁三赛事执行

- **游泳**：按 CSS 配速，前 200m 不冲；开放水域每 6–8 划抬头定位一次。
- **T1**：≤3min，提前想好顺序（鞋/头盔/眼镜/号码带）。
- **骑行**：前 10min Z2 下沿，之后按目标 IF（70.3 ≈ 0.85；Ironman ≈ 0.70–0.75）控功率，**不追超车**。
- **T2**：≤2min，换鞋即跑。
- **跑步**：前 2km 按比目标慢 10–15s/km，之后稳；心率封顶不超过骑行阈值心率。
- **砖训练**至少演练 3 次再比赛。
