# 10 · 越野跑模块（有赛事才展开）

> 触发条件：日历上有 C 级及以上的越野赛，或用户说「这周末去跑山/徒步」。
> 没有越野赛事时，本模块只留「每月 1 次跑山」的维持量，不占用路马的训练预算。
> 与主线冲突时**永远让路 A 赛**：A 赛优先级最高，越野只能当 B/C 赛。

## 1. 三条铁律

1. **越野不上公路配速表**。同样的心率，山地慢 30–90s/km 是正常的，不是退步。
2. **越野不额外加量，只替换**。周日长距离改成「时间 + 爬升」的长课，周跑量不因此上浮。
3. **一次大下坡 = 一次质量课**。下坡的离心负荷 24–72h 才显现，次日不能再排质量课（`03-periodization.md` §7 第 4 条同理）。

## 2. 先做赛事需求分析，再谈练什么

按「赛事需求 → 主限制 → 监测信号」四步走，缺一项就先问，不要编：

| 输入 | 要问清楚 | 影响什么 |
|---|---|---|
| 距离 | 公里数 | 补给档位、长课时长 |
| 爬升/下降 | 累计 D+ / D−（缺下降就按 ≈ D+ 估） | 周爬升剂量、下坡课占比 |
| 技术度 | 可跑林道 / 碎石 / 岩面 / 泥 / 夜段 | 是否需要专门技术课 |
| 关门与检查点 | 关门时间、检查点间距、强制装备 | 配速保守档、携带策略 |

**主限制四选一**（只能选一个先练，选多了等于没选）：

| 主限制 | 典型信号 | 先补什么 |
|---|---|---|
| 有氧底盘 | 平路也撑不住、爬 200m 就爆 | Z2 时间 + 周爬升缓慢递增 |
| 爬坡力量耐力 | 心跳不高但腿先没劲、上坡只能停 | 持续上坡节奏 + 单腿力量/离心 |
| 下坡与技术 | 上坡还行、下坡被超、脚踝发虚 | 短而可重复的下坡课 + 踝髋稳定 |
| 补给与胃 | 3h 后恶心、吃不下、抽筋 | 长课里按小时练吃，不是赛周才试 |

**跨赛事比较只用 km-effort**（ITRA 口径）：`km-effort = 距离km + 爬升m / 100`。
计算交脚本，不要让模型口算：

```bash
python <this skill>/scripts/trail.py --distance-km 50 --climb-m 2500 --descent-m 2400
```

**禁止**：
- 把公路半马/全马配速直接贴到越野赛上；
- 发明「每 100m 爬升加 X 分钟」这类万能公式——没有本人同类数据就只给 RPE 与完赛档；
- 没看赛事手册就输出分段配速表。

## 3. 四项能力（缺哪补哪）

越野不是一种能力，是四种能力共用一个号码布：

| 能力 | 练法 | 监测信号 | 常见短板 |
|---|---|---|---|
| 爬升 | 持续上坡、坡重复、爬楼/跑桥 | 同坡度同心率下的速度、能连续爬多久 | 只会跑不会走，陡坡硬顶 |
| 可跑路面 | 常规 E 跑 / 长课 | 越野后平路配速有没有掉 | 只会爬山，平路反而慢 |
| 技术路面 | 碎石/台阶/土路专项，落脚与视线 | 同段落的稳定度、崴脚次数 | 没练过就上，赛日全靠运气 |
| 下坡 | 短而重复的下坡、离心力量 | 下坡后 48h 的酸痛与膝踝反应 | 把下坡当纯力量，忽略选线与视线 |

自评 1–5 分，**只练最低那一项**，其余维持。

## 4. 怎么塞进现有 4 练

现有结构：周二质量 / 周四质量 / 周六轻松 / 周日长距离（`03-periodization.md` §3）。

| 场景 | 改法 | 硬约束 |
|---|---|---|
| **无越野赛（维持）** | 每 2–3 周把周日 LR 换成「跑山 90–150min，爬升 300–600m」 | 次日只排 E 跑或休息 |
| **备战短越野**（≤25km 或 ≤4h） | 周日改「时间+爬升」长课；周四质量课后加 6×30–60s 短坡；保留周二阈值 | 一周最多 1 次大下坡 |
| **备战中长越野**（≥50km 或 ≥5h） | 需要独立周期（§6），主项让位或降为维持 | 与 A 赛冲突时降级为 B 赛 |

替换而不是叠加：把 LR 换成长课，周总量按 §5 的爬升护栏走，不因为「今天爬得多」就多吃跑量。

## 5. 爬升剂量护栏

- **周爬升增幅 ≤10%**，且**不要和跑量同时加**——一次只推进一个变量。
- 每 3–4 周插一个减载周：爬升 −30~40%，跑量 −15%。
- 峰值周爬升经验区间：**赛事爬升 × 1.0–1.5**（经验值，不是公式；首次越野取下限甚至更低）。
- 单次长课爬升 ≤ 该周总爬升的 60%，剩下的用短坡和日常跑桥补。
- 首次越野的起步量：周爬升 300–600m，能连续 3 周不难受再加。

## 6. 越野专项周期（8–12 周，仅当越野是 A/B 赛）

| 阶段 | 周数 | 重点 | 爬升 | 质量课 |
|---|---|---|---|---|
| 基础 | 4–5 | 有氧 + 爬升耐受 | 平稳递增 10%/周 | 保留 1 次平路阈值 |
| 专项 | 3–4 | 地形匹配（坡度/路面/下坡） | 峰值周 | 上坡节奏 + 下坡技术各 1 次 |
| 减量 | 1–2 | 去疲劳、保脚感 | 降 40–60% | 短坡激活，不试新装备 |

- 与主项周期重叠时：越野按 **B 赛规则**跑（`03-periodization.md` §5），不完整 taper。
- 减量期保留一次短坡（6×30s），保神经兴奋但不产生新疲劳。

## 7. 关键课型（写进 COROS 用）

> 越野在 COROS 里**只支持距离或爬升目标，不支持时间目标**；`等强配速` 绝对值也不支持。
> 所以越野课的写法是：目标用「距离」或「爬升（m）」，强度用「心率区」，坡度/技术/走跑切换写进 description。

### H1 · 短坡重复（力量/神经，准备期）
- 结构：热身 10min → **6–8 × 30–60s 上坡**（能说话变喘、身体还能前倾）→ 走下来恢复 → 冷身 5–10min。
- 单次总爬升 100–200m，动作散了就停，不追组数。
- 次日跟腱/膝更僵 → 取消，退回平路。

### H2 · 持续上坡节奏（力量耐力，专项期主力）
- 结构：热身 10min → **连续上坡 20–40min**，心率 Z3 下沿到 Z3 中段 → 慢跑下山 → 冷身。
- 目标是「可持续」，不是冲到顶；后半段能维持同样步频才算成功。
- 一周最多 1 次，且不在长课后 48h 内。

### H3 · 长课带爬升（time on feet + 补给演练）
- 结构：**时间 90–180min，爬升 300–800m**，全程 Z2；按小时吃胶/固体（§9）。
- 距离写进 COROS，爬升写进 description；不要用公路配速约束。
- 结束后 24h 内不做质量课。

### D1 · 下坡技术（短、可重复）
- 结构：热身 → **4–6 段 2–4min 下坡**，专注视线提前 3–5m、步频快而短、手臂平衡 → 走回起点。
- 结束后做踝/小腿放松；总量不用大，重在**重复和清醒**。
- 第一次做不要超过 20min 下坡总量，逐周加。

### S1 · 越野力量（每周 1–2 次，替代部分常规力量）
- 单腿离心：慢下台阶 3×8/侧、单腿慢下蹲 3×6/侧
- 提踵：站姿提踵 3×12（可负重）、单腿提踵 2×8/侧
- 髋/核心：台阶上步 3×8/侧、侧平板 3×30s/侧
- 放在轻松日或质量课后，**不排在长课前一天**。

## 8. 强度怎么锚

| 地形 | 锚 | 规则 |
|---|---|---|
| 缓上坡（<8%） | 心率 Z2–Z3 下沿 | 能跑就跑，不刻意走 |
| 中等坡（8–15%） | 心率 Z3 | 跑走结合，别硬撑配速 |
| 陡坡（>15%） | RPE 6–7 | **走是合法动作**，杖在练过的前提下才用 |
| 平缓可跑段 | RPE 4–5，能说短句 | 不用下坡「赚时间」补平路的债 |
| 技术/夜段 | RPE 4–5 | 完赛优先，降速不算失败 |

- 心率漂移比平路更明显，山地看 **RPE + 心率区间**，不看配速。
- 训练里出现的「走」，比赛里才敢走；没练过 power hike 的人赛日一定走崩。

## 9. 补给：按小时，不按公里

| 预计时长 | 碳水 | 形态 |
|---|---|---|
| ≤3h（短越野） | 30–45 g/h，或按公路半马档 | 胶为主 + 口渴抿水 |
| 3–8h | 30–60 g/h，**先保证吃得下** | 胶 + 咸软食/赛会热食 |
| ≥8h / 超马 | 同上，来源多样化，后程偏咸 | 固体比例提高；胃翻立刻减量 |

- **水**：口渴再抿，不按固定毫升灌；热天更勤，但别越喝越涨。
- **盐丸不默认用**；抽筋先降强度、补咸食，不是猛吃盐再加速。
- 检查点当战术点：喝水→换水→拿计划内的食物→处理热点→走，目标 1–3min，别坐下。
- **胃和脚是最常见的退赛原因**，不是配速。所有补给必须在长课里试过至少 1 次。

## 10. 赛前与赛后（越野特有）

**赛前**
- 减量 1–2 周：量降 40–60%，保留一次短坡激活。
- 赛前 10 天不试新鞋、新杖、新补给。
- 首野目标只有两个字：**完赛**。

**赛后**
- 24–72h 是离心损伤窗口（DOMS 高峰），**2–3 天不做质量课**，1 周内不排大下坡。
- 0–30min：碳水 + 蛋白 + 补水；当天不泡热水澡、不深揉小腿。
- 1–3 天：走路/极轻松骑车；4–7 天：20–30min E 跑 2 次。
- 10 天后再评估是否需要恢复常规量。

## 11. 红线

- **跟腱 / 髌前 / 膝外侧 / 踝**有症状：先停上坡与下坡专项，用平路 + 慢上坡维持，见 `07-injury-nutrition.md`。
- 夜段、强制装备、头灯、保温层：按**当年赛事手册**准备，赛晨不试新装备。
- 天气：山地比城区低 2–4℃，山脊风更大，用比赛地坐标取数（`09-weather.md` + `weather_policy.venues`）；雷暴/暴雨/结冰按赛事方通知，不擅自冒险。
- 迷路风险：赛前把路线导进手表，不熟的路段不夜跑。

## 12. 数据口径

- COROS 的越野记录看**距离、爬升、心率、时间**；**配速无意义**（受坡度影响），也别拿它和路跑比。
- 跨赛事/跨训练比较用 km-effort（`scripts/trail.py`）；`km-effort` 只用于**同口径排序**，不是成绩预测。
- COROS 的训练负荷已经包含爬升带来的额外负荷，不要再手动加系数。
- 越野和路跑的距离**不能相加**当周跑量写进计划——分开记，越野按「时间 + 爬升」记。

## 14. 来源与改动说明

蒸馏自两个公开的教练知识库仓库（**均未声明开源许可证**，所以这里只吸收框架与判断规则，原文未复制，全部重写并改成本 skill 的口径）：

- [like-a-freedom/agentic_sports_coach](https://github.com/like-a-freedom/agentic_sports_coach) — `mountain-endurance-coach` skill：
  赛事需求分析（DoE）、AeT/LT 双阈值、四段宏观周期、越野四能力（爬升/可跑/技术/下坡）、
  力量阶梯（一般力量 → 最大力量 → 力量耐力）、爬升与周量护栏、补给序列。
- [97657407-cmd/human-upgrade-plan](https://github.com/97657407-cmd/human-upgrade-plan) — `trail-race-framework` / `trail-session-framework` / `hill-run-framework`：
  按小时而非按公里的补给、检查点流程、首野保守档、下坡次日不排质量、上坡课的实际剂量与「别神化」。

**我们改了什么（与来源的差异，重要）**：

1. **不做成绩预测**。来源里有一部分按赛事档位给时长的做法，这里只保留「保守/完赛」两档，不写配速表——本 skill 不允许模型编数字。
2. **裁剪到「一周 4 练 + 骑行交叉」的现实结构**，没有采用 6–7 练模板。
3. **补上 COROS 的落地写法**：越野只支持距离/爬升目标，不支持时间目标与等强配速绝对值。
4. **爬升峰值系数（赛事 × 1.0–1.5）标注为经验值**，不作为公式；首次越野取下限。
5. 与主项冲突时的让位规则按 `03-periodization.md` §5 的 B 赛规则执行。

> 维护：改阈值/剂量 → 改本文件，并同步 `05-workouts.md` 的课型索引；改 km-effort 或周爬升计算 → 改 `scripts/trail.py`，不要在对话里手算。
